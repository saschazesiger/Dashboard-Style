# P3: Controls (1.1.0)

Press, focus and state motion for every control: the shape morph and the micro press-in on all actions, the
pointer ripple on every action host, the focus snap and focus layer on every ring, buttons (busy and success faces,
icon swap), chips, the switch, custom-drawn checkboxes and radios, text fields and one disabled model.

Depends on P1 (layers, Safari 16.4 / Firefox 128 baseline with direct `:focus-visible` and `:has()`, the motion
tokens incl. `--ds-dur-micro`, `--ds-ease-spatial` and `--ds-scale-*`, the `ds-draw` setup, the animated-property allowlist, the exit-ratio table and the
hover and press tests) and on P2 (`DS.ripple` with `ripple.css`, `.ds-pressed`, the `.ds-ripples` layer suppression
for its default hosts, `crossfade()` (kind `'text'`) and `.ds-swap`, `--ds-hold-loader`, `motionDuration()`, `flip()`, `travelDuration()`, the
`fallback` browser project). Ships as **1.1.0**: additive API, and visual changes to existing controls recorded
under "Changed".

Timing used throughout (canonical tokens only):

| Moment | Duration | Curve |
|---|---|---|
| press-in of state layer and radius | `--ds-dur-micro` | layer `--ds-ease-in-out`, radius `--ds-ease-out` |
| radius release (morph back) | `--ds-dur-medium` | `--ds-ease-spatial` |
| state layer release, colours | `--ds-dur-fast` | `--ds-ease-in-out` |
| focus snap (`outline-offset`) | `--ds-dur-fast` | `--ds-ease-out` |
| switch handle travel and size, radio dot, icon-swap scale | `--ds-dur-medium` | `--ds-ease-spatial` |
| switch handle press grow | `--ds-dur-instant` | `--ds-ease-out` |
| chip check slot `width` (layout, D29) | `--ds-dur-medium` | `--ds-ease-out` |
| drawn marks in (stroke, clip wipe) | `--ds-dur-medium` after `--ds-dur-micro` | `--ds-ease-out` |
| marks out, leaving faces and words | `--ds-dur-fast` or `--ds-dur-instant` | `--ds-ease-in` |
