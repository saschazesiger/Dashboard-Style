# P8: Motion Lab, docs completion and final review (1.6.0)

P8 closes the overhaul. It adds the Motion Lab (D12): a second styleguide page with global slow motion, curve and
spring plots, a duration ladder, and a replayable demo with rapid-toggle and interruption benches for every
choreography and every motion primitive. It rewrites `docs/motion.md` into one coherent reference, including the
overlay choreography table. It turns the tests' transitional lists into final guards: no `PENDING` entries, no
`test.fail` for a fixed bug, every demo under test. Then it reviews everything in Chromium, Firefox, WebKit and the
`fallback` project against the P0 baselines.

P8 depends on P1 to P7 being on `main`: the tokens and `--ds-time-scale` (P1), `DS.motion`, `DS.dom` and
`DS.ripple` (P2), the controls (P3), navigation (P4), `DS.overlay` (P5), loaders and data (P6), and View Transitions
and scroll-driven effects (P7). It adds no token, class, keyframe or JS export. What ships in `dist/` is the
completed header comments, the fixes the final review finds, and the version: **1.6.0**.

Canonical names, values and APIs come from [motion-2.md](../motion-2.md). Where this file and that file disagree,
that file wins. Line anchors are taken at `05aaeb3`; P1 to P7 move them, so find each spot by its content.

### Foundations group: curves, springs, durations

- [ ] Curve plots: one inline SVG `.sg-plot` for each easing token: `--ds-ease-in-out`, `--ds-ease-out`,
  `--ds-ease-in`, `--ds-ease-exit`, `--ds-ease-emphasized`, `--ds-ease-spatial` and `--ds-ease-value`.
  `--ds-ease` is listed as "deprecated alias of `--ds-ease-emphasized`" with no plot of its own.
  - Each plot samples the curve the browser actually uses. It reads the token from `getComputedStyle`, then pauses
    a hidden probe that animates `translate` from `0px` to `1000px` with that easing, seeks `currentTime` across
    101 points and reads the computed `translate`. This captures `linear()` overshoot, and in the `fallback`
    project the cubic fallback. No new JS export is needed.
  - Each plot draws the 0 and 1 lines, the [0, 1] band and the sampled path. It writes the peak value in the plot
    caption and as `data-lab-peak` on the SVG. For `--ds-ease-spatial` the peak should be about 1.028; the contract
    is at most 1.05.
  - "Play" runs a ball along each curve over the token's duration, through `el.animate` with the token easing and
    `DS.motion.motionDuration`, so slow motion applies.

  [js-playground]
- [ ] Spring explainer next to the spatial plot. The same `--ds-ease-spatial` drives three boxes for
  `--ds-dur-medium`, `--ds-dur-slow` and `--ds-dur-long` (small control, dialog/FLIP/indicator, sheet/drawer)
  travelling the same distance. The caption says the curve is normalised to its settle time, comes from
  `scripts/motion-curves.mjs`, and that only floating movement overshoots, while layout-pushing sizes land on

## Docs and rules

- **`docs/motion.md`, full rewrite into one reference.** Every `--ds-*` and every export stays documented, as the
  tests require. Sections, in order:
  1. Principles: springs for floating spatial movement only (D1); effects never overshoot; layout-pushing sizes on
     `--ds-ease-out` (D29); hover never moves (D14); press is ripple, layer and morph (D6); interruption continues
     from the current state (D21); data glides with the live guard (D7); the same motion on every device (D8).
  2. Tokens: the duration ladder with its uses, the curve table, the spring contract (peak at most 1.05,
     normalised, generated by `scripts/motion-curves.mjs`), `travelDuration`, distances and scales, and
     `--ds-time-scale` (styleguide and tests only).
  3. Rules, numbered, each tied to its test:
     - what may animate, with the exceptions list identical to `EXCEPTIONS`;
     - curves by role;
     - the exit/entrance ratio 0.3-0.8 and the table of pairs;
     - distances and scales;
     - stagger;
     - data motion;
     - loaders' delay and minimum time;
     - morph instead of re-render;
     - the focus ring solid from frame 1, then the snap.
  4. Choreography: the view entrance order (container first, then content in at most six stagger steps), then one
     table per area:
     - **Overlays**, one row per layer: scrim, dialog, nested dialog, side sheet on desktop and on phone, modal
       drawer, snackbar stack, tooltip including the warm-up, menu and combobox popup. Columns: entrance
       properties, entrance duration and curve tokens, exit properties, exit duration and curve tokens,
       transform-origin (`--ds-motion-origin`), delays, behaviour on interruption, focus during the exit (back to
       the opener at once, D18), and the native or div path. Token names go in backticks, so `lab.spec.js` can
