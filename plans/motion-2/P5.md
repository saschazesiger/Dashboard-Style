# P5: Overlays (1.3.0)

Goal: every floating layer opens and closes the M3 Expressive way and never gets in the way. Native `<dialog>` with
`showModal()` plus a new `DS.overlay` module (D18) for the dialog, the side sheet and the modal drawer. A side sheet
slides its full width on the spatial spring (D16). Menus, the combobox list and tooltips grow out of their trigger
(D17), and tooltips meet WCAG 1.4.13. Snackbars stack, at most three, with FLIP (D19, D32). The new `.ds-menu`
arrives (D26). Every overlay is interruptible (D21): its motion runs on CSS transitions keyed on `data-state`, so a
reversal continues from the current value in every engine.

Depends on:

- **P1**: layers, motion tokens (`--ds-ease-spatial`, `--ds-ease-exit`, `--ds-dur-micro`, `--ds-scale-popup`,
  `--ds-scale-tooltip`; the tooltip delay tokens are added here, see Tooltip), the keyframes `ds-clip-in` / `ds-clip-out`, the movement-only exits, the non-inheriting
  hooks `--ds-motion-origin` / `--ds-clip-from` / `--ds-motion-scale`, the `[hidden]` rules, and `pointer-events: none`
  on the box or panel only while closing.
- **P2**: `settled()`, `leave(el, v, { focus })`, `flip()`, `originFrom()`, `motionDuration()`, the interruption
  mechanism, sibling imports in `src/js/`, and `DS.ripple`.
- **P3**: the focus snap and the focus state layer.
- **P4**: the modal drawer CSS, the `.ds-drawer--instant` hook and the bleed pattern.

What ships as 1.3.0: `src/js/overlay.js` (`DS.overlay`), native dialog and sheet markup, the reworked choreography of
dialog, sheet, snackbar, tooltip and combobox, `src/components/menu.css`, the `.ds-presence` utility, the role
`--ds-scrim-nested` and the hook `--ds-dialog-scrim`. Everything is additive: the div markup, the `--closing` classes,
`.ds-toast--shown`, `--ds-toast-shift` and `data-open` on the combobox keep working. Some of them become deprecated.

Choreography of this phase (exit/entrance ratio on the longest track; the P1 ratio test covers every pair):

| Layer | Entrance | Exit | Ratio |
|---|---|---|---|
| Scrim (dialog, sheet) | opacity, `--ds-dur-medium`, `--ds-ease-in-out` | opacity, `--ds-dur-base`, `--ds-ease-in-out` | n/a |
| Dialog box | opacity `--ds-dur-fast` `--ds-ease-in-out`; `scale` from `--ds-scale-enter` and `translate` from `0 var(--ds-distance-sm)`, `--ds-dur-slow` `--ds-ease-spatial` | the same values back, `--ds-dur-base`; opacity on `--ds-ease-in-out`, movement on `--ds-ease-exit` | .57 |
| Side sheet panel | opaque; `translate` from `var(--ds-distance-sheet) 0` (phones `0 var(--ds-distance-sheet)`), `--ds-dur-long` `--ds-ease-spatial` | back to the edge, `--ds-dur-base` `--ds-ease-exit`, no fade (the canonical exit of panels, as P4's modal drawer) | .44 |
| Snackbar | opacity `--ds-dur-medium` `--ds-ease-in-out`; rise `--ds-distance-md`, `--ds-dur-medium` `--ds-ease-spatial`; siblings via `flip()` | fade `--ds-dur-fast` (`flip()` removal, out of flow) | .6 |
| Tooltip | opacity `--ds-dur-fast`; `scale` from `--ds-scale-tooltip` at the anchor side, `--ds-dur-medium` `--ds-ease-spatial` | opacity only, `--ds-dur-instant` | .4 |
| Menu, combobox list | opacity `--ds-dur-fast`; `clip-path` from `--ds-clip-from` plus `scale` from `--ds-scale-popup` at the trigger, `--ds-dur-medium` `--ds-ease-spatial` | opacity only, `--ds-dur-instant` | .4 |

Menus and the combobox list enter over `--ds-dur-medium`, per the authority's token table ("menu entrances"), not
the `--ds-dur-slow` its spring paragraph names for menus. This keeps their `--ds-dur-instant` exit inside the 0.3 to
0.8 ratio band.

Rest values of `translate` and `scale` are `none`, not `0 0` or `1`. A `position: fixed` popup inside a dialog or
sheet then stays relative to the viewport.

- [x] `open(el, { opener })` recognises its kind: a native `<dialog class="ds-dialog | ds-sheet">`, a div
  `.ds-dialog` / `.ds-sheet`, the modal drawer (`.ds-drawer`), or a popup (`.ds-menu`, `.ds-combo__popup`). The steps,
  in order:
  1. Emit one `console.warn` per page when `!el.closest('.ds-theme')`.
  2. Hide any visible tooltip.
  3. If `el` is closing, supersede the close with a generation token. The pending close promise resolves without
     acting, and the motion reverses from the current value by flipping `data-state`. If `el` is already open, do
     nothing.
  4. Store `opener ?? document.activeElement`.
  5. Modal kinds call `lockScroll()` and push `el` on the stack.
  6. Native: `showModal()`. Div: drop `hidden` / `.ds-dialog--hidden` / `.ds-sheet--hidden`, then set `inert` on every
     sibling of `el` and of each of its ancestors up to `<body>` that is not inert yet, skipping `.ds-scrim`. Record
     exactly those elements, so close restores only them and nested overlays compose.
  7. Set `data-state="closed"`, flush style (`getComputedStyle(box).opacity`), run `originFrom(opener, box)` for
     dialogs and popups (the box is laid out in its closed state by then), then set `data-state="open"`.
  8. Move focus: `[autofocus]` inside the box or panel, else its first focusable element. Popups: a menu focuses its
     first enabled `.ds-menu__item`, and a combobox keeps focus in its input. Focus moves synchronously. That is fine,
     because the box is opaque within `--ds-dur-fast`.
  9. Popups set `aria-expanded="true"` on the opener.
